# Historical source policy

The older `guide-lines-on-fraud.pdf` contains earlier fraud classification and reporting guidance, including older monetary thresholds and procedures.

The RBI 2024 Master Direction states that it supersedes the earlier 2016 fraud-classification/reporting directions.

RAG rule:
- Current-rule query → prefer RBI 2024.
- Explanatory query → RBI 2024 plus PwC if useful.
- Historical-comparison query → deliberately retrieve the older source and label it historical.
- Never silently combine historical and current requirements.
